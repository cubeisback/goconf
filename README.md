# GoConf (Next.js версия)

## Установка

```bash
npm install
```

## Запуск в режиме разработки

```bash
npm run dev
```

## Сборка

```bash
npm run build
```

## Запуск в production

```bash
npm start
```

---

Проект конвертирован из CRA в Next.js с использованием новой маршрутизации (`app/`). Все страницы были перенесены в `app/`, а `ui.jsx` перемещен в `styles/ui.js`.
